Components

States drawn side by side: idle, hover, focus, pressed, disabled and marked. Focus is always a 3 px brown-deep ring with a 2 px gap.

Buttons

Primary is ink on gold. Inside an exercise nothing is gold except what the user marked, so finishing early is brown. Both Osa 1 answers use the same neutral key, so neither reads as the recommended one.

Marks — one language in every exercise

A mark is highlighter wash plus a 3 px pen line, never colour alone and never a weight change, so text does not reflow and it survives greyscale.
